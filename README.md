# Digital Growth Hub

Crie um website profissional moderno para minha empresa chamada LPweb.dev.

O projeto deve funcionar como uma LANDING PAGE DE CAPTAÇÃO DE CLIENTES, mas também como um MINI SITE PROFISSIONAL onde os visitantes possam conhecer a empresa, seus serviços, portfólio e entrar em contato.

O principal objetivo do site é transformar visitantes vindos do Instagram em potenciais clientes.

IMPORTANTE:

O site deve ser pensado PRIMEIRAMENTE PARA MOBILE, pois a maior parte dos visitantes virá através do link do Instagram.

Também deve ser totalmente responsivo e funcionar perfeitamente em desktop, tablet e celular.
